Site estático (didático) gerado por script.

- O site “voto tardio” é gerado por `primeiro-turno/scripts/09_build_site_voto_tardio.py`.
- A versão “completa” (concentração + biometria + discrepância) pode ser gerada por `06_build_site_didatico.py`.
- Este diretório não precisa ter conteúdo versionado além destes arquivos de orientação.

Como gerar (a partir da raiz do repo):

```bash
python3 primeiro-turno/scripts/09_build_site_voto_tardio.py
```
